# Dee Builds

Portfolio website for Disha Agarwal.

## Structure

- `index.html` holds the page sections and visible copy.
- `assets/css/styles.css` controls the full visual design and responsive layout.
- `assets/js/projects.js` is the easiest place to add, remove, or edit projects.
- `assets/js/main.js` handles project rendering and subtle scroll reveal motion.
- `assets/img/` stores the avatar and project screenshots.
- `assets/resume/` stores the downloadable resume.

## How to preview

Open `index.html` in a browser, or run a small local server from this folder.

## Current direction

The visual system is based on a dark purple, pink, and glassy glow palette with softer typography:
Oswald for headings, Roboto Slab for expressive lines, and Roboto Condensed for readable interface text.
